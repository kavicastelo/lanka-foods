# 08 — Migration Risk Register

This register details all technical, architectural, security, and data integrity risks identified in the codebase, prioritized by severity.

---

## Risk Register

| Risk ID | Severity | Risk Description | Affected Files & Lines | Impact | Migration Implication | Target Phase |
|---|---|---|---|---|---|---|
| **RISK-01** | **P0** | **Base44 Platform Lock-in / Hard Dependency**: The application cannot perform any data fetching, login, or order placement without active Base44 SDK credentials. | [base44Client.js:7](file:///d:/talnova/lanka-foods/src/api/base44Client.js#L7), [AuthContext.jsx:28-48](file:///d:/talnova/lanka-foods/src/lib/AuthContext.jsx#L28-L48) | Complete functional blockage when disconnected from Base44 services. | A standalone Node.js REST API and MongoDB database must be built from scratch. | Phase 1 - 3 |
| **RISK-02** | **P0** | **Direct Client Entity Mutations**: Frontend code executes direct `base44.entities.Restaurant.update()`, `Review.delete()`, and `RestaurantApplication.create()` calls. | [RestaurantAdminDashboard.jsx:271](file:///d:/talnova/lanka-foods/src/pages/RestaurantAdminDashboard.jsx#L271), [SuperAdminDashboard.jsx:366](file:///d:/talnova/lanka-foods/src/pages/SuperAdminDashboard.jsx#L366), [Register.jsx:72](file:///d:/talnova/lanka-foods/src/pages/Register.jsx#L72) | Critical security vulnerability and data integrity bypass. | All database tables must be encapsulated behind server-side Node REST controllers with role authorization. | Phase 3 - 6 |
| **RISK-03** | **P1** | **Unencrypted LocalStorage Authentication Tokens**: JWT tokens are stored in unencrypted browser `localStorage` and read from URL query parameters. | [app-params.js:23,30](file:///d:/talnova/lanka-foods/src/lib/app-params.js#L23), [AuthContext.jsx:42](file:///d:/talnova/lanka-foods/src/lib/AuthContext.jsx#L42) | Vulnerable to XSS token exfiltration and session hijacking. | Migrate authentication to HttpOnly, SameSite cookies or secure Authorization headers. | Phase 3 |
| **RISK-04** | **P1** | **Missing Order Payment Processing**: Orders set `payment_status: "pending"` without invoking any real payment gateway. Orders are treated as placed immediately. | [Checkout.jsx:153-162](file:///d:/talnova/lanka-foods/src/pages/Checkout.jsx#L153-L162), [placeOrder/entry.ts:134](file:///d:/talnova/lanka-foods/base44/functions/placeOrder/entry.ts#L134) | Financial loss risk: Customers can place unpaid orders under "Card" or "Mobile payment" selection. | Implement payment gateway integration (Stripe / Paytrail) with webhook verification. | Phase 7 |
| **RISK-05** | **P2** | **TypeScript & ESLint Build Errors**: `npm run typecheck` fails with 40+ TS errors and `npm run lint` fails with 10 unused import errors. | [Restaurants.jsx:66](file:///d:/talnova/lanka-foods/src/pages/Restaurants.jsx#L66), [RestaurantStorefront.jsx:49,97](file:///d:/talnova/lanka-foods/src/pages/RestaurantStorefront.jsx#L49), `eslint.config.js` | Code quality degradation and potential runtime prop bugs. | Resolve TS prop types and remove unused imports in future refactoring. | Phase 14 |
| **RISK-06** | **P2** | **External Base44 CDN Media Asset Dependencies**: Static image assets rely on `https://media.base44.com/images/public/...`. | [constants.js:5-11](file:///d:/talnova/lanka-foods/src/lib/constants.js#L5-L11), [SignIn.jsx:33](file:///d:/talnova/lanka-foods/src/pages/SignIn.jsx#L33) | UI image breakage if Base44 media CDN becomes inaccessible. | Upload assets to Cloudflare R2 / S3 storage and update image URLs. | Phase 14 |
| **RISK-07** | **P3** | **Unused Heavy NPM Packages**: `package.json` includes `three`, `html2canvas`, `jspdf`, `moment`, `react-quill-new`, bloating bundle size over 1 MB. | `package.json:14-100` | Slow bundle loading times (1 MB JS asset). | Prune unused dependencies from `package.json` and enable Vite chunk splitting. | Phase 14 |
